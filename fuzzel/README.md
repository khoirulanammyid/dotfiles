# My Fuzzel Setup

Application launcher (rofi-style) used for app launching, power menu, and pickers:

- **FantasqueSansM Nerd Font** at 14pt
- Centered **overlay layer**, 110-wide window with 10 lines
- Opens apps in `alacritty`
- **Gruvbox colors**: `#ebdbb2` text on `#2b2421`, `#fabd2f` match highlight, flat 1px border
