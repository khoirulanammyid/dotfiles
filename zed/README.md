# My Zed Setup

Zed editor config:

- **Gruvbox Dark Hard** theme, **JetBrainsMono Nerd Font** UI font, `server` window decorations (no title-bar buttons)
- **Agent servers** — opencode (`opencode/big-pickle` model) and antigravity ACP (gemini), right dock
- **LaTeX** — `texlab` LSP builds `main.tex` with `latexmk -pdf -synctex=1` and forward-searches into `zathura`
- **Keybindings** — toggling the four panels, file finder, outline, project-panel vim-style file ops, new terminal
- Defaults: open in existing window, 100-col line length, bounded soft wrap
