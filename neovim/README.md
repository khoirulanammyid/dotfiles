# My Neovim Setup

[LazyVim](https://lazyvim.org) distribution:

- `init.lua` bootstraps `lazy.nvim` (cloned on first run) and loads the **LazyVim** plugin spec plus local `plugins/`
- Custom `lua/config/` for options, keymaps, and autocmds
- Quickstart distribution defaults; add your own plugins under `lua/plugins/`
