# My Music Setup

Local music streaming stack:

- **`mpd`** server — music dir `~/Music`, state/db in `~/.config/mpd`, binds `127.0.0.1:6600`, PulseAudio/PipeWire output
- **`rmpc`** client — TUI frontend for MPD: hot-reload config, lyrics, mouse support, browser view sorted by disc/track/artist/title
