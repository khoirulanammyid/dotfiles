# My Yazi Setup

Terminal file manager (`yazi`) config:

- **gruvbox-dark** flavor, plain-border plugin
- **`allmytoes`** previewer for images (from the `bin` package), with ImageMagick (`magick`) fallback for svg/heic/jxl
- Plugin/flavor deps (full-border, allmytoes, kanagawa, gruvbox) pinned in `package.toml`
