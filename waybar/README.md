# My Waybar Setup

Status bar (`waybar`) config, Gruvbox Flat-black theme:

- **Left** — niri workspaces + focused window title
- **Right** — `wireplumber` volume (click to mute via `wpctl`), backlight %, network (wifi/ethernet/OFF), idle inhibitor (CAFF/IDLE), tray, battery, clock
- **Clock** — `%a %b %d %H:%M` with a clickable year **calendar tooltip** in Gruvbox colors
- Styling in `style.css`: `FantasqueSansM Nerd Font`, `#121212` bar with an active-workspace accent
