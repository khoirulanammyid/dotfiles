# My Kew Setup

Terminal music player (`kew`) config:

- Music directory set to `~/Music`
- AlbumCover color mode with a full **theme pack** (gruvbox, kanagawa, catppuccin, nord, tokyonight, etc.) and custom layouts
- Enables **crossfade** between tracks
- **Visualizer** (vibrant bars), in-terminal album covers
- Track notifications, auto-resume, animated song title in window title
- Simple vi-style keybindings and mouse support
